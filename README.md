# Time For Change

A small browser-based helper for keeping an eye on a car and the things that wear out in it. Add a vehicle, note its mileage, and keep track of parts that will eventually need a change.

It is a plain static page with no backend and no build step. Everything is stored locally in the browser, so the list is still there after a refresh.

## Run it

Serve the folder with any static server, for example:

```sh
python3 -m http.server
```

Then open `http://localhost:8000`.

Live version: https://iams1lv3r.github.io/time-for-change/
